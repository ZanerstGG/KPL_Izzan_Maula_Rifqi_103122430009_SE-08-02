## Soal
Jelaskan dengan kemampuanmu apa itu event delegation dalam design pattern JavaScript. Tidak ada batas bobot kata dalam menjawab tugas ini, tetapi penilaian akan bergantung dari sepaham apa dan sebagus apa kamu menyajikan jawabanmu.

## Deskripsi
Event Delegation dalam JavaScript adalah sebuah teknik optimasi DOM yang sebenarnya merupakan penerapan dari Observer Pattern.

Konsep dasarnya sederhana, dimana daripada kita menempelkan event listener satu per satu ke banyak elemen anak, kita cukup "mendelegasikan" tugas mendengarkan interaksi tersebut ke satu elemen induknya. Hal ini dapat dilakukan karena adanya sifat alami DOM JavaScript yang disebut Event Bubbling, dimana sebuah interaksi (seperti klik pada tombol) akan merambat atau menggelembung naik dari elemen anak terdalam hingga ke elemen induk di atasnya. Dengan event delegation, elemen induk tinggal menangkap event yang merambat naik tersebut dan mengecek dari mana asalnya (biasanya menggunakan event.target), lalu menjalankan logika yang sesuai.

Jika dianalisis dari sudut pandang Software Engineering, penerapan pola ini memberikan dua keuntungan besar, yaitu Sangat menghemat penggunaan memori browser karena sistem hanya perlu menyimpan satu listener di elemen induk, bukan ratusan listener di setiap elemen anak dan Pola ini sangat mudah menangani elemen dinamis, Misalnya pada aplikasi To-Do List, ketika ada baris tugas baru yang ditambahkan oleh sistem secara real-time, kita tidak perlu lagi memasang listener baru ke tombol hapus di tugas tersebut, karena elemen induknya sudah otomatis mengcover tangkapan event-nya.

Intinya, Event Delegation adalah cara kita membuat implementasi Observer Pattern di sisi frontend menjadi jauh lebih efisien, tidak kaku, dan aman dari risiko kebocoran memori.
