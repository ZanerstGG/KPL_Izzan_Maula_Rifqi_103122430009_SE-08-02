## Soal
Dari dua kode di bawah ini, mana yang kamu ingin cari masalahnya dan perbaiki di tengah-tengah malam, katakanlah jam 1 malam? Mengapa?
```javascript
function processUser(user) {
  if (user) {
    if (user.isActive) {
      if (user.hasPermission) {
        return doSomething(user)
      }
    }
  }
  return null
}
```
```javascript
function processUser(user) {
  if (!isValidCandidate(user)) return null;
  return doSomething(user);
}

function isValidCandidate(user) {
  return user && user.isActive && user.hasPermission;
}
```

## Deskripsi
Jika saya disuruh melakukan debugging pada jam 1 malam disaat fokus dan kapasitas kognitif sudah sangat menurun, maka aku langsung memilih untuk menangani Kode Kedua.

Alasannya adalah, Pada kode pertama itu contoh nyata dari arrow anti-pattern. Penggunaan nested if yang berlapis-lapis membuat bentuk kodenya menjorok ke dalam menyerupai mata panah, sehingga Saat otak sedang lelah, mata akan sangat kesulitan dan cepat lelah untuk me-tracking kurung kurawal mana yang menutup kondisi if yang mana, karena seolah dipaksa memecahkan teka-teki logika bercabang hanya untuk memahami satu alur saja.

Sebaliknya, Kode Kedua terasa jauh lebih mudah karena sudah direfaktorisasi menggunakan teknik early return atau guard clause, Karena alih-alih membungkus proses utama di dalam blok if, kode ini meletakkan kondisi penolakan di baris paling awal (`if (!isValidCandidate...) return null;`). Hasilnya, struktur kode menjadi datar dan alurnya dapat dibaca lurus secara sekuensial dari atas ke bawah. Membaca kode ini di tengah malam akan sangat menghemat beban kognitif otak.
Selain itu, Kode Kedua juga sudah mengikuti prinsip Separation of Concerns dimana satu fungsi hanya melakukan satu tugas, karena Logika rincian untuk memvalidasi user telah dipisah ke dalam fungsi `isValidCandidate()`. Jadi, misalnya error pada tengah malam itu disebabkan oleh kegagalan sistem dalam membaca izin, kita cukup mencari dan memperbaiki fungsi `isValidCandidate()` tanpa perlu mengotak-atik fungsi utama `processUser()`.
